# Movie Trailers Hub

A small website with movie trailer pages for different genres and languages.

## What is included

- `index.html` - Main page with featured trailers
- `trailer.html` - Latest Telugu trailers
- `action.html` - Action trailers
- `comedy.html` - Comedy trailers
- `drama.html` - Drama trailers
- `sc-fi.html` - Sci-Fi trailers
- `thriller.html` - Thriller trailers
- `hindi.html` - Hindi trailers
- `style.css` - Shared styles for layout and responsive design
- `images/` - Banner and page images

## Responsive support

The website works better on different screen sizes, including:

- desktop
- laptop
- tablet
- mobile

## Open the site

1. Open `index.html` in your browser.
2. Use the menu to choose a category.
3. Play trailers on each page.

## Notes

- Every page includes the viewport meta tag for mobile browsers.
- `style.css` has responsive rules for smaller screens.
